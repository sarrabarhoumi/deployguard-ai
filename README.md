# DeployGuard AI

AI-powered deployment risk analyzer integrated with GitHub CI/CD pipelines.

## Overview

DeployGuard AI analyzes code changes before deployment to identify potential risks such as:

- Dangerous database migrations
- Security issues
- Configuration changes
- Docker changes
- Kubernetes changes
- API modifications
- Failed tests

The platform combines deterministic DevOps rules with Large Language Model analysis to generate structured deployment risk reports.
